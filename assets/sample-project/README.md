# Projet d’exemple — Mon Tactical RPG

Copie du projet « Mon Tactical RPG » : données, cartes, textes, plugins et ressources propres au jeu.
Les sauvegardes de parties ne font pas partie du modèle.

À la création d’un projet d’exemple, l’application copie les ressources par défaut,
les packs listés dans `template.json` et les images d’interface du moteur, puis applique
les fichiers de ce dossier. Les ressources propres aux personnages et cartes du projet
sont conservées ici ; les ressources communes déjà fournies par l’application sont réutilisées.
`resource-paths.json` conserve l’orthographe exacte des chemins du projet d’origine,
notamment les majuscules et minuscules utilisées par les fiches de personnages et de classes.

Le nom saisi dans « Nouveau projet » remplace celui du modèle. Le modèle reste indépendant
du dossier de travail d’origine et des nouveaux projets créés à partir de lui.
