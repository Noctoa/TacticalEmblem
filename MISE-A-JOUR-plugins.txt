Mise à jour : système de plugins
================================
Basée sur la version GitHub « Merge branch 'main' » (8d0d419).

Installation
1. git pull
2. Extraire ce zip à la racine du dossier TacticalEmblem (remplacer les fichiers)
3. Lancer nettoyage-ancien-pack.bat : supprime assets\packs (l'ancien pack GBA), devenu le dossier plugins\
   (puis valider ces suppressions dans git)
4. Lancer update.bat

Plugins
- Base de données > Plugins : plugins installés dans le projet + plugins fournis avec Tactics Forge.
  « Installer dans le projet » copie les ressources (sans écraser) et relie les images aux classes,
  terrains et personnages de la série. « Installer depuis un dossier… » : tout dossier avec un plugin.json.
  Activer / désactiver, relier de nouveau, désinstaller.
- plugins\ : fe6-binding-blade, fe7-blazing-blade, fe8-sacred-stones, customs-style-gba (ressources)
  et exemple-annonce-tours (script d'exemple).
- Scripts : TacticsForge.register / TacticsForge.on (voir README, section Plugins).
